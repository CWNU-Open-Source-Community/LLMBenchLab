# Phase 5：Agent/Tool Use、私有 Benchmark 与 Live Benchmark

- 状态：`planned`
- 前置阶段：[Phase 3 — Benchmarks](PHASE-3-BENCHMARKS.md) 的沙箱/插件能力与 Phase 2 的可靠调度
- 可选依赖：[Phase 4 — Judge & Arena](PHASE-4-JUDGE-ARENA.md) 的开放式评审能力
- 后续阶段：[Phase 6 — Public Release](PHASE-6-PUBLIC-RELEASE.md)

## 阶段目标

在可回放、最小权限且无真实副作用的工具环境中评测模型的多步任务能力，并用隔离私有集与持续轮换的 Live Benchmark 降低污染和针对性过拟合。

## 功能范围

- Agent Episode、Tool Call、Observation、环境状态、终止原因与成功规则。
- 工具注册表、JSON Schema 校验、权限 allowlist、网络/时间/步骤/费用限制。
- 环境快照、确定性夹具、轨迹持久化、回放和人工复核。
- 任务成功率、步骤效率、无效/越权调用、恢复能力、延迟与成本指标。
- 私有 Benchmark 加密存储、最小权限、答案隔离、审计和脱敏导出。
- Live Benchmark 发布、密封、冻结、轮换、退役、泄漏处置和时间窗口。

## 非目标

- 不允许 Agent 默认访问宿主文件、真实账户、生产系统或无限制公网。
- 不把私有题目、参考答案、隐藏工具状态或完整敏感轨迹公开。
- 不在本阶段实现公共注册、组织级多租户或商业化托管。

## 依赖

- Phase 2 的可靠队列、取消、预算、审计和并发控制。
- Phase 3 的插件、安全隔离和不可信输入处理基础。
- Phase 4 Judge 仅可辅助开放式轨迹评分，不能替代客观成功条件。
- 私有数据密钥管理、保留周期和访问审批方案已通过安全评审。

| ID | 任务 | 输出 |

| P5-01 | Agent 协议 | Episode/Tool/State/Score Schema、协议与 ADR |
| P5-02 | 工具运行时 | 注册表、参数校验、权限、隔离、预算与取消 |

| P5-07 | 安全与复现 | Prompt injection、越权、泄漏、预算与重放测试 |

## 验收标准

- [ ] 固定环境快照和输入可重放轨迹，并区分模型与环境非确定性。
- [ ] 未注册工具、非法参数、越权文件/网络访问默认拒绝并留审计记录。
- [ ] 步数、时间、Token、费用和副作用限制有端到端测试。
- [ ] 工具异常、模型异常、策略拒绝和任务失败分类清楚。
- [ ] 客观成功判定与 Judge 辅助评分分离，评分可解释且可复核。
- [ ] 私有题目/答案不出现在普通 API、日志、前端包或公开导出中。
- [ ] Live 版本具有生效、冻结、退役时间和不可变 Hash，历史结果可追溯。
- [ ] 泄漏演练、密钥轮换、访问撤销和备份恢复验证通过。

## 风险

| 风险 | 应对 |
| --- | --- |
| 工具产生真实副作用 | 仿真/临时环境、默认拒绝、显式 allowlist、幂等或可回滚操作 |
| Prompt injection 获取隐藏答案 | 模型可见数据与评分数据物理/逻辑隔离，canary 与泄漏检测 |
| 私有数据经日志或导出泄漏 | 字段级脱敏、最小权限、审计、加密和导出审批 |
| 环境漂移破坏复现 | 版本化镜像/夹具、环境 Hash、时间和外部依赖快照 |
| Live 轮换削弱跨期可比性 | 固定评测窗口、保留版本化历史，不跨窗口无提示排名 |

## 交付物

- Agent/Tool Use 协议、受控 Runner、工具 SDK 和参考环境。
- 轨迹存储/查看/回放与分层指标报告。
- 私有 Benchmark 保险库、权限/密钥/审计机制。
- Live Benchmark 生命周期服务、泄漏响应与运营手册。

## 状态

`planned`。在工具权限和私有数据威胁模型通过评审前，不得接入真实账户或敏感数据。
